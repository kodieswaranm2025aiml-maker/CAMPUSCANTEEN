# Demo Script

1. Start MySQL and run `mvn spring-boot:run`.
2. Open `http://localhost:8080`.
3. Register a student account and log in.
4. Browse the menu, select quantities and place an order.
5. Show the generated token and total.
6. Open a second browser session and log in as `staff / staff123`.
7. Open Manage Orders and update an order to PREPARING, READY or COMPLETED.
8. Open Manage Menu and add a food item or toggle availability.
