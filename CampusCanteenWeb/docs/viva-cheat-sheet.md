# Viva Cheat Sheet

- Spring Boot: Java framework used to build stand-alone web applications quickly.
- Architecture: layered MVC architecture.
- Controller: receives HTTP requests and returns views/responses.
- Service: contains business rules such as order validation and bill calculation.
- Repository: performs database access using Spring Data JPA.
- Entity: Java class mapped to a database table.
- JPA: Java persistence specification for mapping objects to relational tables.
- Hibernate: ORM implementation/provider used by JPA.
- Thymeleaf: server-side template engine used to generate HTML pages.
- Spring Security: handles login, authentication and role-based access.
- Maven: manages dependencies and builds/runs the project.
- CRUD: Create, Read, Update and Delete.
